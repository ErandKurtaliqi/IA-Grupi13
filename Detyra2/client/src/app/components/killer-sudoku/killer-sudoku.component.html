📚 About Killer Sudoku

Killer Sudoku combines elements of Sudoku and Kakuro. The objective is to fill the grid with numbers 1-9 following these rules:

  • Each row contains 1-9 without repetition
  • Each column contains 1-9 without repetition
  • Each 3×3 box contains 1-9 without repetition
  • Numbers in a cage must sum to the cage's total
  • Numbers cannot repeat within a cage
